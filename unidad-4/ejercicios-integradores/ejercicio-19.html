Ejercicio integrador 19

19. Integración: Tomando la integración del punto 12, agregar un botón selector (select) desplegable que permita
seleccionar la figura que desee cargar (Círculo, Polígono) e incorpore un nuevo objeto llamado “CakeGraph” (Gráfico de torta circular) de modo que procese un JSON que contenga en su interior
la descripción de datos que corresponda para representar un gráfico de tortas. Cada región (tajada) se rellena con un color aleatorio de forma automática. Es decir, no debe suministrar colores.

Json de circulo:
{"x": 300, "y": 200, "radius": 80}

Json de poligono:
{"x": 500, "y": 350, "points": [{ "x": 0, "y": -80 }, { "x": 70, "y": 50 }, { "x": -70, "y": 50 }]}

Json de torta:
{ "x": 400, "y": 300, "radius": 100, "data": [ {"value": 0.3}, {"value": 0.5}, {"value": 0.1}, {"value": 0.1} ] }
